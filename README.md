# Vedant Dagwar - Portfolio Website

A premium, dark-themed portfolio website for Business Analyst Vedant Dagwar.

## Features

- Dark luxury theme with gold and teal accents
- Animated particle constellation background
- Smooth scroll animations
- Responsive design for all devices
- Interactive project cards with spotlight effect
- Animated statistics counters
- Mobile-friendly navigation

## File Structure

```
static-portfolio/
├── index.html          # Main HTML file
├── styles.css          # All styles
├── script.js           # JavaScript functionality
├── images/
│   └── vedant-profile.png  # Profile photo
└── README.md           # This file
```

## Setup for GitHub Pages

1. Create a new repository on GitHub
2. Upload all files from this folder
3. Go to Settings > Pages
4. Select "Deploy from a branch"
5. Choose "main" branch and "/ (root)" folder
6. Click Save
7. Your site will be live at `https://yourusername.github.io/repository-name`

## Customization

### Colors
Edit the CSS variables in `styles.css`:
```css
:root {
  --primary: #c8a96e;      /* Gold */
  --secondary: #4ecdc4;    /* Teal */
  --background: #05070f;   /* Dark navy */
}
```

### Content
Edit `index.html` to update:
- Personal information
- Experience details
- Projects
- Skills
- Contact information
